FAQ

Questions people ask first.

Will it merge code on its own?

No. It opens a pull request on a showwork/ branch and stops. It does not merge, approve, or write to your default branch. A person merges.

Does AI-generated code run on our servers or laptops?

Generated code runs only inside sealed Docker containers with no network, a read-only repository and a hard deadline. It never runs on the host.

How is this different from other coding agents?

Many agents open PRs. Showwork's focus is proof: independent test cases, real-browser runs at three sizes, results read from recorded runs rather than claimed, and gates that bind each approval to the exact thing approved.

What does a run cost?

On our sample benchmark tickets, between about $0.50 and $2, with model usage as the main cost. Your tickets and codebase will differ. Per-run and daily budgets cap spend in code.

What if the ticket is vague?

The PM agent asks. The run is marked Blocked, questions are posted on the Jira ticket, and it continues by itself when the reporter replies. Contradictions in the criteria are named at the first gate.

Which models does it use?

Gemini on Google Vertex AI by default, with a provider switch for Anthropic's Claude.

Can we run it ourselves?

Yes. It installs on one server with Docker Compose. See Trust and platform for what is and is not supported yet.

What if a run cannot be finished safely?

It hands over to a person with a clear account of what was done and what is left, instead of opening a doubtful pull request. Budgets, time limits and gates are enforced in code.

What is on the roadmap?

A designer agent and design gate, task splitting for large tickets, assertion-level QA and isolated agent environments. See the roadmap.
